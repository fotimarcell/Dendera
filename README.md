# Dendera

A denderai padló és az ég összevetése. A fugák, az átlók és a kövek irányát méri a Naphoz, a Holdhoz, a bolygókhoz és a fényes csillagokhoz.

## Indítás

```bash
npm install
npm run dev
```

A fejlesztői lap a `http://127.0.0.1:8080` címen nyílik.

## Ág

A `main` ág a közösen használt állapot. Minden önálló változtatás külön mentés, rövid üzenettel: mi változott, és miért.
